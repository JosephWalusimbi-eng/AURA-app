# AURA

A free, offline personal assistant for Android and Windows that sets reminders and alarms by voice or typing and
learns your own voice and accent on your device. Built for East African English at Soroti University, Uganda.

**Website:** https://josephwalusimbi-eng.github.io/AURA-app/

## Download (version 0.1.1)

See the [latest release](https://github.com/JosephWalusimbi-eng/AURA-app/releases/latest):
Android APK (64-bit phones, Android 6+) and Windows ZIP (64-bit, Windows 10+), with SHA-256 checksums and install
steps. The Microsoft Store version is coming.

## Models

- Accent adapters and merged models: https://huggingface.co/Walusimbi/whisper-afrispeech-east-africa
- Wake word: https://huggingface.co/Walusimbi/aura-wakeword
